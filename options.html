Video Flow

Bring your own API keys

Keys stay in this Chrome profile and are sent only to Supadata (for YouTube) and the AI gateway. This open-source extension has no developer server or analytics.

Transcript provider

Used to fetch timestamped YouTube subtitles. Bilibili videos need no key. Create a Supadata account and key. Supadata generates the key during onboarding.

AI provider

OpenAI compatible Fixed Base URL

The Base URL is fixed and cannot be changed. Your API token is sent only to this address.

Models load automatically after you enter the token.

When you use AI features, the gateway at the Base URL receives the video transcript and relevant video context. Review its terms and pricing before saving.
Local remix Want to use another AI model? Edit and copy a safe prompt for your coding agent Coding agent ready

You can edit the prompt directly. Complete these three steps before copying:

  1. Open the extracted Video Flow project folder in your coding agent.
  2. Replace [PROVIDER] and [MODEL] with the service and model you want to use.
  3. Never include API keys in the prompt or chat. Enter them yourself after the code is ready.
